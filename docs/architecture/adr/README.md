# Architecture Decision Records

This directory stores all ADRs for NutriCoach AI.

## Format

Use the template at `docs/governance/ADR_TEMPLATE.md`.

## Naming

`ADR-NNN-short-title.md` — e.g. `ADR-001-supabase-backend.md`

## Status Lifecycle

1. **Proposed** — under review
2. **Accepted** — approved for implementation
3. **Deprecated** — no longer recommended but kept for history
4. **Superseded** — replaced by a newer ADR (link both ways)
